# Smart Farmer local produce image library

## Inventory summary

The library contains **88 unique local JPEG files**: 86 crop-specific photographs and 2 general category photographs. All **71 crops** in the documented inventory now have exact photos; no inventory crops remain without a specific image. The 20 newly added Commons photos are optimized to 960 px wide or smaller. Existing photos are 1200 px wide or smaller, at most 1800 px high, and no larger than 527,979 bytes. The web UI lazy-loads and asynchronously decodes photos. Photo cards use `object-fit: cover` and meaningful alt text. The crop-to-photo and crop-to-category resolver is centralized in `frontend/js/produce-images.js`.

Exact photos are only assigned to the crop shown in the photograph. Unsupported crops may use a representative category fallback when a suitable local category image exists. The fallback is not represented as an exact crop photograph. If no suitable fallback exists, the photo element stays hidden rather than showing an unrelated crop. Unrecognized names are classified as Other Crops and use the general mixed-produce photo with representative alt text.

## Crop-specific photo inventory

Source file pages, author attribution, and licence information are recorded for every exact photo. Existing Unsplash photos use the Unsplash License; Wikimedia Commons photos use the specific CC0, CC BY, or CC BY-SA licence shown in their rows. Newly added Commons photos were resized and JPEG-optimized for web display. Their derivative files retain the source licence; CC BY-SA derivatives are offered under the same or a compatible licence, and author/source credits are listed here.

For botanical accuracy, the resolver treats Sinhala `නිවිති` as Sri Lankan Nivithi (`Basella alba`). True spinach (`Spinacia oleracea`) uses its scientific name, the Sinhala transliteration `ස්පිනච්`, and Tamil `பாலக் கீரை`; this avoids assigning one ambiguous local label to two different species.

Sri Lankan tuber names are kept distinct: this resolver follows the [CGIAR Sri Lankan tuber crop table](https://cgspace.cgiar.org/bitstreams/500bdc2a-ec89-4e6e-8232-105824ad4cb2/download) for Kiriala as `Colocasia esculenta` (taro/Gahala), and the [Sri Lanka Department of Agriculture HORDI Kiri Ala reference](https://doa.gov.lk/hordi-crop-kiri-ala/) for Kiri Ala as `Xanthosoma sagittifolium` (Desi ala). A [Wayamba University of Sri Lanka symposium abstract](https://flfn.wyb.ac.lk/wp-content/uploads/2019/FLFN/Abstract/abstract-book-2017.pdf) also uses Kiriala for Xanthosoma, so Sri Lankan common-name usage is not fully consistent; the resolver keeps separate, taxon-identified photos and exposes scientific-name aliases to disambiguate. The Kiri Ala image shows photographed Xanthosoma corms.

## Mapping and filtering behavior

- The central mapping is `frontend/js/produce-images.js`; it exports the crop photo resolver, category classifier, and shared category-filter renderer.
- Existing Farmer-added listings are categorized from the crop name unless an existing `categories.category_name` value is present. No database column or record is changed by the classifier.
- Public produce, Buyer Browse Produce, Farmer My Produce, and their full-list views use the same classifier. Full-list views reuse the Buyer and Farmer dashboard templates.
- Category filters are client-side and compose with the current produce search and district filters. They use real listings only and do not show category counts.
- Existing database category names are selected with read-only LEFT JOINs where produce listings are loaded. New listings with no stored category are classified in the application.
- Missing exact photos are explicitly listed above. Until a suitable licensed image is added, the resolver uses the available category fallback or omits the image if that category has no suitable local photograph.
